Put the original reel files here, named after the id in src/app/data/brand-media.ts:

  xbhB5GjSMsQ.mp4     (vertical 9:16, H.264/AAC, ideally under 15 MB each)

The site plays a file from this folder in its own player, with no third-party branding.
A reel without a file here falls back to the YouTube player automatically.
To change the cover image of a reel, set `poster` on its entry in brand-media.ts.
